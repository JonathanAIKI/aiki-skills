# AIKI Skills — gratis AI-skills for norske bedrifter

Praktiske Claude-skills som løser konkrete oppgaver i arbeidshverdagen. Bygget av [AIKI](https://aikias.no), et norsk AI-selskap. Gratis å bruke, ingen betingelser.

Hver skill er laget for å virke rett ut av boksen, på norsk, med realistiske eksempler.

## Installer på 30 sekunder

```bash
git clone https://github.com/JonathanAIKI/aiki-skills ~/.claude/skills/aiki
```

Restart Claude Code, kjør `/skills`, og pakken er klar til bruk.

## Pakkene

### Automasjon
For vareflyt, verksted, bygg, industri og logistikk.

| Skill | Hva den gjør |
|---|---|
| `ordrebekreftelse` | Lager ferdige ordrebekreftelser fra kunde, varer, antall og pris, med mva og summer |
| `tilbud-generator` | Gjør en jobbspesifikasjon om til strukturert tilbud med poster, summer, forbehold og gyldighet |
| `faktura-matching` | Matcher innkommende faktura mot ordre linje for linje og flagger avvik og dobbeltfakturering |
| `leveranse-status` | Skriver kundevennlige statusmeldinger ved forsinkelse, sporing eller ny leveringsdato |

### Kundeservice
For helse og klinikk, reiseliv og hotell, handel og retail.

| Skill | Hva den gjør |
|---|---|
| `henvendelse-triage` | Klassifiserer og prioriterer innkommende henvendelser med tema, hastegrad og foreslått neste steg |
| `svar-mal-bygger` | Bygger gjenbrukbare, merkevare-tilpassede svar-maler for gjenganger-spørsmål |
| `booking-svar` | Skriver bekreftelser, alternativforslag og avbestillinger for time- og rombestilling |
| `anmeldelse-svar` | Formulerer gode offentlige svar på Google- og Trustpilot-anmeldelser |

### Partner
For regnskap, juridisk, rådgivning og arkitekt.

| Skill | Hva den gjør |
|---|---|
| `klient-oppdatering` | Gjør korte notater om til profesjonelle status-oppdateringer til klienter |
| `dokument-oppsummering` | Oppsummerer lange dokumenter og kontrakter til nøkkelpunkter, risikoer og handlingspunkter |
| `mote-til-oppgaver` | Gjør møtenotater om til konkrete oppgaver med ansvarlig og frist |
| `frist-assistent` | Lager fristoversikt og sjekklister for terminer og leveranser |
